# Sales Performance Analytics – Python Data Analysis Project

## Overview

This project is a practical **Sales Performance Analytics** project developed using **Python and Google Colab** with the Superstore sales dataset.

It demonstrates an end-to-end data analysis workflow, including:

- Data loading and inspection
- Data cleaning and transformation
- Exploratory Data Analysis (EDA)
- Sales and profit analysis
- Category, regional, customer, and product analysis
- Monthly and yearly sales analysis
- Data visualization
- Business insights and recommendations
- Final reporting

## Tools & Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## How to Use

### Option 1: Google Colab

1. Open [Google Colab](https://colab.research.google.com/).
2. Upload/open the provided notebook file(s).
3. Upload the dataset when the notebook asks for it, or place the dataset in the location expected by the notebook.
4. Run the notebook cells from top to bottom.
5. Review the generated analysis, visualizations, and insights.

### Option 2: Local Python Environment

If you prefer to run the project locally:

1. Install Python 3.x.
2. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

3. Open the notebook in Jupyter Notebook/JupyterLab.
4. Make sure the dataset is available at the path expected by the notebook.
5. Run the cells in order.

## Project Workflow

**Data → Inspection → Cleaning → EDA → Visualization → Insights → Final Report**

## Dataset

The project uses the **Superstore sales dataset** for analyzing sales performance, profitability, products, customers, categories, regions, and time-based trends.

## Important Notes

- This project is intended for **learning, educational, and portfolio purposes**.
- If a notebook contains a dataset path specific to Google Colab, update the path when running it in another environment.
- Do not modify the original dataset if you want to reproduce the analysis exactly; make a copy first.
